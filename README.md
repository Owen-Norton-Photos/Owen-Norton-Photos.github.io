# goldcoolness1-ops.github.io

Keep each year's photos in `2025pic/` or `2026pic/` and list them with their capture dates in `gallery-data.js`. The browser sorts this small local list newest-first and loads the image files directly from the site; it makes no GitHub API calls and doesn't fetch image metadata. Use `YYYY-MM-DDTHH:MM:SS` for dates. Markup is generated from the sorted list, and images are lazy-loaded as needed.
